# Security Policy

## Supported Versions

The PUQ PVE OS Builder follows a rolling release cycle. Security updates are applied to the `latest` Docker image. We highly recommend always running the most up-to-date version of the container.

| Version | Supported          |
| ------- | ------------------ |
| `latest`| :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

Security is a top priority for us. If you discover a security vulnerability within this project, please DO NOT open a public issue.

Instead, please send an e-mail to **support@puqcloud.com**.

We will promptly acknowledge your email, review the issue, and provide a timeline for addressing the vulnerability. Please allow us time to patch the issue before disclosing it publicly.

Thank you for helping keep our project safe!
